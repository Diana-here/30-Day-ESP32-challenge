# ESP32 30-Day Learning Challenge

Hi!

This repository is a companion to the **30-Day ESP32 Learning Challenge** I'm sharing on Instagram ([@dianawired](https://instagram.com/dianawired)). Every reel in the series has a matching folder here with the full code and any extra resources you need to follow along.

Feel free to clone, remix, break, and optimize any of these projects — that's exactly what they're here for.

## How this works

For 30 days, we tackle one new ESP32 concept a day and build something small to put it into practice. At the end of each week, those daily lessons come together into a **Mini-Project**. After Week 4, everything gets pulled together into one final, full-fledged project to close out the challenge.

Each day's folder generally includes:
- The code for that day
- A short explanation of the concept
- Wiring notes / a diagram, where relevant

## Getting started

1. Clone this repo: `git clone <repo-url>`
2. Open the folder for the day you're on
3. Flash the code to your ESP32 and follow along with the reel

Questions at any point? DM me on Instagram at **[@dianawired](https://instagram.com/dianawired)**.
